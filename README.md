# Keystone

Landing page for **Keystone**, an AI after-hours call dispatcher for commercial and industrial trade contractors. It was built as an entrepreneurship-class venture at Ohio State (pre-pilot, no live deployments yet).

- **Live page:** https://raisemuck.github.io/keystone-site/
- The 52-second sample call on the page is synthetic: a scripted demo, not a real customer call.
- Plain HTML/CSS/JS on GitHub Pages, with a contact form for pilot interest.
